# 0.3.0 完整包验收

> 本节保留 0.3.0 历史基线。0.3.1 的新增验收见本文末尾。

此版本改变环境分发与组件查找方式，保留现有媒体处理、索引和桌面交互实现。

## 功能与环境

- 内置 CPython 运行 95 项后台测试：94 项通过，1 项因当前 Windows 无符号链接创建权限跳过。
- 前端 23 项检查通过，包括内外拖放、原始文件拖出请求、多选、Shift 连续范围与右键操作。
- 桌面 62 项检查通过，包括原生文件路径、后台身份、旧版本拒绝和隔离启动。
- 固定 WebView2 152.0.4191.62 在独立临时配置中启动，实际完成页面加载、JavaScript 和 Canvas 检查；这项检查指定随包路径，不复用系统浏览器。
- 完整 ZIP 解压到中文含空格路径，清空 PATH 中的 Python/FFmpeg 并设置无效的外部 Python 环境路径后，内置环境仍能启动。实际生成合成图片和 H.264 视频，完成导入、尺寸识别和两类 JPEG 缩略图。
- 包内文件清单、SHA-256、ZIP CRC 和唯一应用根目录逐项验证；测试未打开用户项目。

## 同机性能对比

使用同一份临时生成的十万条素材索引，比较本机旧后台使用的 CPython 3.11.9 与完整包 CPython 3.13.15。两个解释器交替运行三轮；每轮各场景测八次，去掉首个预热样本，以下为剩余 21 个样本的中位数。操作系统文件缓存没有清空。

| 场景 | 旧解释器 | 内置解释器 |
| --- | ---: | ---: |
| 常规列表 | 71.55 ms | 61.52 ms |
| 中文搜索 | 119.17 ms | 89.81 ms |
| 分类与状态筛选 | 59.66 ms | 55.83 ms |
| 按名称排序 | 88.89 ms | 85.99 ms |
| 按顺序排序 | 89.38 ms | 81.81 ms |
| 跳到第九万项 | 130.96 ms | 133.70 ms |

这些结果未显示整体明显退步；深分页约 2% 的差异不能据此判定稳定退步或提升。这是同机合成数据库检查，不代表所有电脑、媒体编码或磁盘条件的性能保证。没有将包体积减少与运行速度混为一谈：完整包增加下载和磁盘占用，正常启动不重复解压运行时，缩略图仍按需处理。

当前真实运行时检查使用 Windows 11 x64。Windows 10 的兼容处理遵循微软固定 WebView2 分发要求，但没有声称在所有 Windows 版本和硬件上实测通过。

## 0.3.1 增量验收

- 新版源码完整 Python 回归 133 项：132 通过，1 项因 Windows 符号链接权限跳过。
- 前端共 55 项断言通过（Node runner 计 46 项，其中项目库脚本内含 10 项）；覆盖项目库分类与共享弹窗生命周期、设置持久化请求、连续外部打开排队、只读预览、搜索、回收及原有拖放/多选。
- Windows 桌面 94 项断言通过：75 项核心、CLI、单实例管道和打开方式注册检查，19 项实际 WinForms 托盘与退出生命周期检查。
- 原生 Windows 回收使用新建临时文件和嵌套目录验证，回收目标实际存在，逐文件 SHA-256 保持一致；合成项目经 HTTP 预览与删除后列表为空，旧恢复请求拒绝。
- 实际前端完成设置保存、项目分类创建、项目归类与返回浏览；修复共享 dialog 旧关闭事件覆盖新表单的问题。
- 交叉审查修复了页面故障退出死路、外部打开并发丢请求、回收后数据库写失败导致假恢复、硬链接绕过外部预览目录限制，以及不可用按钮的提示文案。
- ZIP 与下载后复验由发布流程执行：完整包逐文件摘要、隔离启动、图片/视频索引和缩略图均成功后才公开 Release。旧版本附件保留。

设置不包含永久删除选项。项目库分类不搬动原目录；外部文件只读预览不复制文件或写入项目。直接播放仍受 WebView2 编解码支持限制。

### 隔离原生增补

实际隐藏 WebView2 与独立临时 profile 已验证：引擎缩放规范化触发真正的 ZoomFactorChanged，产品百分比回调随之更新；产品按钮点击后实际 ZoomFactor 与标签同步回到 100%。普通 ZoomFactor 赋值按官方 SDK 约定不触发事件，按钮已显式刷新标签。独立 probe 通过，LifecycleTests 的显式 `--zoom-integration <缓存浏览器目录>` 模式新增 5 项通过；该模式只运行离线缩放检查，不连接后台、不显示窗口、不触发截图或剪贴板。测试产生的临时目录需在进程退出后清理，以免删除仍映射的原生程序集。

合成位图在 640、800、1280 像素宽度下验证标注工具条 6 个控件的边界与离屏渲染，按钮不裁切，选区后等待确认。隐藏原生组合框的离屏打印不完整显示选中文本，因此不能据此确认实际字体/下拉操作；真实 Ctrl+滚轮、交互式标注及托盘完整路径仍未由本项覆盖。没有新的整机性能实测。
