# 映序功能指南

[返回映序](../README.md) · [安装与运行](安装与运行.md) · [开发说明](开发说明.md)

本指南对应 **0.4.1**。从项目建立、素材进入、文件编辑到审核和交接，按日常操作查找入口即可。

## 1. 建立作品的项目空间

左上“项目空间”旁的 **＋** 创建项目，填写名称和简介。项目会生成普通目录和必要的项目入口文件；项目名称可以通过项目旁的“…”菜单修改，修改显示资料不会搬动项目根目录。

| 左侧分类 | 建议放什么 |
| --- | --- |
| 剧本与文档 | 故事大纲、完整剧本、分集梗概、制作笔记 |
| 分镜 | 镜头脚本、镜号与视听参数、分镜参考 |
| 角色 | 角色设定、三视图、服装、表情与参考图 |
| 场景 | 环境设计、空间基准、场景图片 |
| 道具 | 道具设定与图片、关键物件 |
| 白模预演 | 3D 源文件、空间预演、白模渲染视频 |
| 生成素材 | 已生成的图片与视频、候选版本 |
| 成片交付 | 最终成片、交付说明及相关文件 |
| 参考资料 | 风格、历史、视觉或技术参考 |

这些分类用于组织，不限制同一文件与多个镜头建立关联。

## 2. 建文件夹，按集数整理

先进入一个分类，点击顶部 **“新建文件夹”**。打开文件夹后继续新建，即可建立更深层级。示例结构：

```text
角色
├─ 跨集共用
│  ├─ 主角
│  └─ 固定配角
├─ 第 1 集
│  └─ 临时角色
└─ 第 2 集
```

用顶部路径导航返回上层。文件夹可通过“…”或右键菜单进入、重命名、在资源管理器打开或删除。文件夹改名会同步项目内的真实目录；同名冲突不会覆盖已有目录。

共用角色只需保留一个条目，再关联到不同分镜。文件夹负责存放，关联负责表达“这个镜头用到了谁”。

## 3. 文件怎样进入项目

| 方法 | 操作 | 磁盘上发生什么 |
| --- | --- | --- |
| 拖入文件 | 打开目标分类 / 文件夹，从资源管理器拖进工作台 | 复制到项目，外部原件保留 |
| 导入已有文件或目录 | 点“导入”，选择文件 / 文件夹或填入绝对路径 | 建立引用，原文件不复制、不搬动 |
| 新建文档或分镜 | 在对应位置新建并写内容 | 在项目内创建 Markdown 文件 |
| 同步项目文件 | 外部工具改过文件后点击“同步项目文件” | 增量刷新索引，保留标签、状态和关联 |

大型已有素材库适合引用导入，减少重复占用。引用文件仍可在支持的编辑器中保存，**保存会修改那个源文件**，此前版本会备份；引用不等于不可编辑的副本。

## 4. 移动、命名与打开文件夹

### 调整位置

- 将文件卡片拖到左侧分类、当前文件夹卡片或路径导航。
- 也可以在文件的“…” / 右键菜单中选择 **“移动到…”**，再选择分类和目标文件夹。
- 勾选多项后使用顶部 **“移动到”**，一次处理所选文件。

项目内文件会实际移动；外部引用只调整工作台的分类和文件夹，保留源位置。目标有同名文件时会提示冲突，不覆盖原文件。批量移动失败时会回滚本次操作。

### 两种名称

| 入口 | 影响 |
| --- | --- |
| 右侧制作信息中的“显示名称” | 只改卡片和标签页上的名称，不改变磁盘文件名 |
| “文件重命名”或右键“重命名文件” | 同步真实文件名，保留扩展名，更新映序中的文件引用 |

### 在资源管理器中找到内容

0.2.1 支持在文件卡片、列表行、项目或目录入口使用右键菜单。文件选 **“打开所在文件夹”**，文件夹选 **“打开文件夹”**，项目选 **“打开项目文件夹”**；右侧资源信息也保留“定位文件”。菜单还可以通过“…”打开。

支持键盘菜单键或 `Shift+F10` 打开当前元素的菜单，方向键切换选项，`Esc` 关闭。目录入口只定位目录，不运行目录中的文件。

### 把文件交给其他软件

桌面版打开文件后，按住右侧 **“拖出文件”** 手柄，拖到资源管理器或支持接收文件的剪辑软件。它交出实际文件路径并保留原件。不同应用的接收行为取决于该应用；不接收时先“打开所在文件夹”，再从资源管理器操作。普通浏览器使用目录定位入口。

## 5. 在多标签工作区写文档

点击卡片打开标签页，继续点击其他文件可多开。切换标签不会立刻丢弃未保存内容。可拖动分隔线改变区域宽度，通过工具栏收起右侧资源信息，扩大编辑空间。

| 文件类型 | 当前工作方式 |
| --- | --- |
| Markdown / 文本 | 直接输入，支持编辑、预览及分栏，`Ctrl+S` 保存 |
| `.docx` | 读取并编辑普通正文段落，保存前备份；复杂结构按提示只读 |
| 图片 | 大图预览，查看文件信息与可读取的生成元数据 |
| 视频 / 音频 | 在播放器中预览，能否解码取决于本机环境 |
| PDF | 通过内嵌浏览组件查看；环境不支持时用本机应用 |
| 3D / 其他文件 | 管理分类、状态和关联，使用“本机打开”交给对应程序 |

关闭有修改的内容时会提示保存、放弃或继续编辑。文件若被其他工具更新，保存会检查版本，避免直接覆盖外部修改。侧栏“保存前的版本”显示已保留的本地备份；页面草稿不代替文件保存和完整备份。

`.docx` 提供正文、标题、表格与内嵌图片的结构预览。切换“编辑文字”修改可安全处理的段落；未编辑文字的 run 样式和包资源保留。精确分页、页眉页脚、浮动图形与旧 `.doc` 仍请使用 Word / WPS。

## 6. 标签、待审核与分镜信息

### 标签在哪里添加

1. 打开文件，在右侧 **“资源信息 → 制作信息”** 找到“标签”。
2. 输入例如 `信封，关键道具，第1集`，用逗号分隔。
3. 点 **“保存制作信息”**。卡片下方就会显示标签。

标签没有预设含义，可按作品需要命名。右侧不见时，点击工具栏 **“显示资源信息与关联”**。

### 待审核在哪里看

同一面板中的 **“制作状态”** 可以选择：待开始、进行中、待审核、已完成。设置后保存制作信息。

集中查看时，先选择 **“全部资源”**，在列表上方 **“全部状态”** 中选择 **“待审核”**。在某一分类内筛选，只显示那一类的待审核文件。看板也可以按状态查看工作。

### 分镜怎么记录

展开 **“分镜与生成参数”**，填写镜号、时长、景别、摄影机 / 运镜、提示词、反向提示词、种子、版本和模型。制作备注可记录下一步调整意见。

“原文件中的生成信息”来自可识别的 PNG 元数据，可查看与复制；它与自己填写的制作参数分开保存。文件中不存在这些信息时不会凭空生成参数。

## 7. 让分镜与素材互相对应

在右侧 **“关联资源 → 添加关联”** 中选择用途，再搜索当前项目内的文件。可关联角色、场景、道具、白模参考、生成版本、关联文档与参考资料。

例如：镜头 `01-03` 关联“主角设定”“雨夜街口”“信封”“白模预演 v1”和“生成视频 v3”。后续打开镜头就能找到这次创作采用的资料，也能从关联端继续查找。

解除关联只删除关系，不删除文件。目录、标签、状态和关联分别表达存放位置、检索词、制作进度和创作关系，可以组合使用。

## 8. 搜索与筛选

按 `Ctrl+F` 聚焦当前页面已有的搜索框。可以输入普通中文，也可组合条件：

```text
雨巷 tag:夜景 type:video status:待审核
```

表示同时匹配“雨巷”、夜景标签、视频类型和待审核状态。支持 `tag:`、`type:`、`status:`、`category:`；例如 `category:scenes` 表示场景。高级检索提供类型和状态控件，无需记住所有语法。

搜索在当前项目、分类和文件夹范围内生效。需要找整个项目时先回到“全部资源”；文件夹直属与全部范围也会影响结果。列表按页展示，不会为了翻页把全部素材持续堆进页面。

## 9. 删除与恢复

文件、文件夹、项目和自建 SKILL 都有删除入口。选中多个文件可批量删除；操作前会确认，完成后可立即“撤回”，也可从左侧 **“回收站”** 恢复。

- 删除会从工作台当前列表移出，**磁盘文件保留**。
- 文件夹 / 项目删除按本次操作记录批次，恢复不会把更早已经删除的条目全部重新加回。
- 所属项目也被删除时，先恢复项目，再处理其内部条目。
- 外部 SKILL 使用“隐藏”，源技能文件不卸载；恢复后可重新参与工作台使用。
- 回收站支持名称搜索与分页。

需要进一步清理时，在回收站条目右侧点 **“删除”**，或使用顶部 **“清空回收站”**。映序先列出原文件位置、外部引用说明与冲突原因；确认后，把可处理的项目内文件移入 Windows 回收站。清空操作针对全部回收条目，不受搜索和分页影响。

成功后条目不再出现在映序回收站，也不能从映序点击恢复。误操作时，请到 Windows 回收站还原文件；如需恢复映序的制作状态和关联，仍应保留应用数据备份。外部引用与外部 SKILL 只清理映序记录，原文件保留。已恢复、被其他项目使用、包含未知内容或在预览后发生变化的对象会被拒绝；失败条目保留记录。程序不会降级为永久删除。

## 10. 集中管理 SKILL

左侧 **“SKILL 库”** 可搜索和查看本机用户技能。默认发现 `.codex/skills`、`.claude/skills` 中的用户技能；点“扫描本机 SKILL”刷新。

已有技能只读，需要调整时使用 **“复制为我的 SKILL”**；也可创建新技能，写下自己的视听规范、角色一致性要求或审核方法。在技能右侧点 **“加入当前项目”**，将它写入该项目的交接资料。项目绑定可以随时解除。

绑定表示让后续协作者知道这份规范的位置与用途，不会自动安装、执行或上传技能。

## 11. 把当前进度交给 Codex

进入 **“AI 协作 · 项目交接”**。页面显示最近汇总时间和同步状态；变更未汇总时先“刷新进度”，然后“复制给 AI 的交接指令”。

项目中有这些普通文件：

| 文件 | 内容 |
| --- | --- |
| `AGENTS.md` | 新项目的协作入口，指向项目交接内容 |
| `.yingxu/PROJECT_CONTEXT.md` | 可读的项目说明、当前进度与协作线索 |
| `.yingxu/progress.json` | 结构化制作进度、目录和状态 |
| `.yingxu/files-index.jsonl` | 按行保存的文件索引，便于逐条读取 |

在 Codex 或其他具备本地文件读取能力的工具中打开项目目录，再告诉它：

> 先读 AGENTS.md 和 .yingxu/PROJECT_CONTEXT.md，告诉我目前做到哪一步，再按我的要求继续。

快照会标记生成时间。映序提供本地交接资料，不会替你发送任务；向外部工具分享文件前由你决定分享范围。

## 0.3.0：直接拖拽与连续多选

- 图片、卡片和列表行都能直接按住拖动，无需点小箭头。放到映序内分类或文件夹会移动；拖到桌面、资源管理器或支持文件接收的软件会交付原始文件，保留映序内原件。
- 先点第一项，再按住 Shift 点最后一项，选中当前页面中间整段素材；也支持从后往前选。Ctrl 点选增减单项，Ctrl+Shift 可追加一段。复选框同样支持 Shift 连选。
- 连选按当前可见顺序生效，翻页、筛选或切换分类后重新选择起点。选中多个素材后，拖动其中任意一项即可一起拖拽。


## 0.3.7：截图标注、缩放与拖动归类

项目库中的项目使用长条行显示，可拖到其他项目分类，也可拖出弹窗放到工作台的空白区域，归入“未分类”。素材组弹窗中的成员同样使用长条行，可拖到同项目的其他素材组，也可拖出弹窗放到空白区域，移出当前组。按 Esc 取消拖动；取消、无效目标或请求失败保留原归属。跨组转移作为一次操作提交，不先移出再另行添加。

这些操作只改变映序的逻辑归类，不移动、复制或删除磁盘原文件，也不改写正文。项目分类和素材组是不同层级；素材组不能跨项目转移成员。

素材选择框保持焦点时也可按 Delete，将当前项目、本页实际选中的素材移入映序回收站。普通输入控件、无关勾选框、编辑器、输入法组合和弹窗继续屏蔽该快捷键；不处理隐藏组成员，无有效选区时不删除当前打开的文稿或文件夹。确认开关、未保存草稿保护和恢复流程保持不变。

### 截图：标注后确认或快速完成

设置中的“截图方式”提供两种选择，默认 **标注后确认**。按原快捷键 **Ctrl+Alt+Shift+S** 或点击截图按钮，冻结鼠标所在的屏幕，再拖动选区。默认模式下，松开鼠标后停留在选区，可用画笔、箭头或矩形，调整颜色和粗细、撤销上一步，然后点击确认。确认后才复制到剪贴板、保存项目附件，并按原笔记状态决定是否插入 Markdown 草稿。

选择 **快速完成** 则保留原来的松开鼠标即完成行为。两种模式都支持 Esc 或右键取消；标注工具条也有取消按钮。取消不会改变剪贴板或新增项目附件。截图仅在触发时读取单块屏幕，冻结后复用该画面；不持续采集屏幕，不增加运行依赖。

### 界面缩放百分比

原生窗口状态栏右侧显示“界面 100%”等实际 WebView 缩放比例，Ctrl+滚轮缩放后随之更新。点击百分比恢复界面 100%。该比例表示整个工作台界面缩放，与图片预览中图片自身的缩放不同。图片工具栏另显示“图片 N%”，按原图尺寸和实际显示区域计算；可放大、缩小或点击“适应”。适应窗口时比例会随可用区域变化，未载入图片时显示“图片 —”。

## 0.3.6：标题改名与 Delete 快捷键

点击编辑区上方的项目文件标题，打开“重命名磁盘文件”弹窗。输入框只填写文件名称，不含 `.md` 等原扩展名；修改后点击确认，沿用原有安全重命名流程，原扩展名保持不变。取消弹窗不会改变文件。

标题仍独立于正文，不写入文稿第一行。重命名不会保存、丢弃或重建当前尚未保存的正文，原草稿继续保留，可随后使用 Ctrl+S 保存。它是确认式重命名弹窗，不是标题内逐字自动修改磁盘文件名。

在资源区选中一个或多个素材后按 **Delete**，将所选素材移入映序回收站，可在回收站恢复。是否弹出确认沿用“设置”中的普通删除确认选项。编辑标题、正文或其他输入框时，Delete 只删除文字，不会删除后台仍选中的素材。

## 0.3.5：独立标题、图片与素材组

### 文件名与正文

文件名称位于编辑区上方独立标题行，不显示 `.md` 等扩展名；0.3.5 中标题仅作显示，0.3.6 的点击改名见上一节。正文 Ctrl+A 只选择文稿，不包含文件名。已有文稿第一行不删除、不改写；新建普通笔记为空正文，分镜与 SKILL 的显式模板保留。可编辑 Markdown 的实时、源码与双栏模式提供撤销/重做、H1–H6/正文、粗体、斜体、删除线、项目/编号/任务列表、引用、链接、分隔线和代码块。所有操作直接修改 Markdown，切换模式保留撤销记录。

### 按需截图

在桌面窗口点击顶栏或文稿工具栏的截图按钮，或按 **Ctrl+Alt+Shift+S**。映序停在托盘时快捷键也可触发；在设置中可关闭后台快捷键或改用至少两个 Ctrl/Alt/Shift 修饰键，加字母、数字或 F1–F24（F12 除外）。组合被其他程序占用时会提示，可换组合或使用按钮。

只截取发起时鼠标所在的一块屏幕。0.3.5 的松开鼠标即完成行为在 0.3.7 保留为“快速完成”；当前默认“标注后确认”，操作见上方 0.3.7 节。Esc 或右键取消，取消不写剪贴板和项目。屏幕上限为 4000 万像素，不拼接多个显示器。截图没有持续屏幕录制、剪贴板读取或后台轮询。

完成后图片复制到剪贴板，同时作为附件保存到发起时项目的“参考资料”。若当时有可编辑 Markdown，且返回时仍为原项目、原笔记、原草稿并未进入预览或中文输入组合，图片链接插入原选区末尾成为草稿，不覆盖已选正文（包括 Ctrl+A 全选）；使用 Ctrl+S 保存后才写入笔记。两项结果独立提示：剪贴板失败仍可保留项目附件，项目保存失败仍可保留已复制的图片。无项目或项目上下文超时不会猜测目标，仅尝试复制到剪贴板。

本地图片在实时预览、双栏或只读预览中显示。实时模式选中图片会展示原 Markdown 供编辑。图片必须已登记在同一项目内、是独立光栅文件且不超过 32 MiB；外部 URL、SVG、越界路径和共享链接不内嵌，原语法保留。移动文件后相对路径可能需要同步并调整链接。

以下为 0.3.5 快速截图的历史验收，不代表 0.3.7 标注流程已经完成真实交互验收：已实测映序窗口内触发、其他应用位于前台时的后台快捷键触发、实际屏幕上的合成区域选择、项目附件保存和 Markdown 图片内嵌；575×250 像素截图与剪贴板图像逐像素 RGBA 匹配。正常关闭至托盘后，全局快捷键能唤起截图遮罩已实测；托盘状态下的选区完成及真实 Esc 取消尚未验收，不同 DPI 的多屏组合亦未实测。

### 空白拖框选择

从资源滚动区空白处按住鼠标左键拖动，也可从卡片下方空白向上框选。只命中本页可见资源（默认每页 48 项），不选择组内隐藏成员；Ctrl 切换命中项，Shift 追加，Esc 或取消手势恢复开始时的选择。卡片、按钮和文稿正文不启动框选。拖动时支持边缘滚动；系统减少动态效果时关闭自动滚动，仍可手动滚动。

空白处单击或未达到拖动阈值时保留已有选择；普通拖框替换选择，Ctrl/Shift 组合可保留或切换已有项。位置只在手势开始时缓存，移动合并到动画帧，选择集合变化才更新界面；停止拖动后不运行框选 RAF、计时器或后台请求。这是实现范围，不能替代所有机器的性能验收。

### 逻辑素材组

选择至少两个同项目素材，从右键菜单创建素材组；也可把卡片拖到另一张卡片上稍作停留后叠放成组，或拖入已有组。组卡片显示预览和数量，“管理素材组”可打开组、改名、添加或移出成员、解散组。可以跨项目内分类归组，但不能把不同项目混成一组；同一素材一次只属于一个组。0.3.7 起可从组成员弹窗直接拖到另一组，由后台一次完成转移，无需先手动移出。

组只是索引关系，不移动或复制文件，不修改分类、制作状态与关联。移出成员或解散组不会删除素材。每项目最多 500 组，每组最多 200 个成员（包含暂在回收站的成员）；并发变更以修订号检查，过期操作需刷新。

## 0.3.4：跨项目全局搜索

按 **Ctrl+K**，或点击顶栏 **“全局搜索”**，打开独立的搜索窗口。它检索所有项目的名称与简介、文件名称/标签/备注和已索引正文（含提取的 DOCX 正文），以及已注册 SKILL 的名称、描述和限额正文，不受当前项目、分类或文件夹筛选限制。**Ctrl+F** 继续聚焦当前页面的搜索框。

结果显示所属来源和命中摘要，并可分页查看。用上/下方向键选择结果，按 Enter 打开，按 Esc 关闭窗口。达到扫描上限时，窗口明确提示当前只展示部分结果，可以缩小关键词范围后继续查找。

搜索使用已保存、已索引的内容，未保存草稿不进入索引。在其他软件修改项目文件后，先用“同步项目文件”更新索引；SKILL 搜索仅涉及已经注册的技能，正文读取有大小和扫描限额，不扫描任意磁盘目录。

顶栏帮助图标位于设置图标左边，设置图标在最右侧；两项保留悬停说明和键盘访问。

## 0.3.3：Markdown 实时预览编辑

可编辑的 Markdown 文稿与映序自建 SKILL 默认打开实时预览模式。将光标放入段落后，该段显示 Markdown 源码，其他支持的内容保持排版显示；工具栏仍可切换源码、双栏或只读预览。

选中文本后使用 **Ctrl+B** 或 **Ctrl+I**，也可以点击标题、粗体、斜体、列表、引用按钮。所有操作都修改同一份 Markdown 文本；切换显示模式不会把渲染后的 HTML 转换回文稿。

超过 50 万字符、或文件混用了不同换行方式时，编辑器使用源码模式。复杂表格、YAML、HTML、代码和图片保留源码表示。外部只读文稿与外部 SKILL 保持只读。中文输入法组合期间不会重建或关闭编辑器；完成输入后再切换或关闭，草稿与保存提示跟随当前文本状态，原文件的 BOM 和换行方式保持。

## 0.3.2：右键笔记与快捷入口

- 在项目素材区右键选择“新建笔记”，笔记会放入当前分类或文件夹。
- 在 SKILL 上右键选择“打开文件位置”，Windows 会定位原技能文件；外部技能仍保持只读。
- 顶栏的设置与使用指南图标分别打开对应内容，鼠标悬停可查看说明，也可通过键盘访问。

## 0.3.1：项目库、设置与托盘

点击侧栏“项目库”，用分类文件夹整理长期项目。可创建多层分类、改名、移动分类和给项目归类；只能删除不含当前项目和子分类的空分类。回收中的项目若原分类已删除，恢复后进入未分类。分类只改变项目库归属，不移动磁盘目录。打开项目后侧栏最多显示当前与最近 5 项，全部项目仍可从项目库检索。

点击“设置”可分别控制普通删除、清理回收站时是否弹出确认，默认开启。关闭提示后仍会校验删除范围、共享引用和文件变化；存在无法处理的条目时继续显示原因。只有 Windows 确认回收成功才清除映序记录。

还可设置关闭窗口后留在托盘、启动时视图与排序、音视频自动播放。托盘图标双击重开，右键可打开工作台、设置或退出桌面窗口；退出前处理未保存文稿。后台索引服务独立运行，避免关闭桌面打断导入。

“打开本地文件”支持 Markdown/文本直接编辑，Word 结构预览与安全文字编辑，其他媒体按类型预览；也可在设置中将映序添加到 Windows“打开方式”候选，并可随时撤销。该操作不替换系统默认应用。支持文本、Markdown、Word 正文、PDF、图片、音频和视频；不复制原件、不自动加入项目。视频能否直接播放取决于 WebView2 解码支持。外部预览在后台重启后需重新打开文件。
# 批量添加标签和修改制作状态

勾选或框选多项素材后，点击工具栏「批量编辑」，或右键选择「批量添加标签」「批量修改制作状态」。多个标签用逗号分隔，原有标签会保留，重复标签自动合并。制作状态默认「保持各自状态」，选择新状态后统一应用；也可以同时添加标签和修改状态。

弹窗会显示本次选中的数量。标签留空且状态保持不变时不会提交；如果部分条目已删除或追加后标签超限，整批不会修改。选中素材若有未保存的制作信息，会先提示保存或继续编辑；批量操作不改动文稿正文和素材原文件。

## 0.3.8：文件打开、文档预览与播放修复

- 完整 ZIP 包含灰绿色“界面 100%”桌面状态文字，悬停才显示下划线，点击恢复 100%。
- 项目库每个项目右侧有“重命名”，仅改项目名称，不移动目录；“未分类”是内置分组。
- 关闭最后一个视频/音频标签释放播放器；切换标签停止旧媒体，关闭窗口留在托盘也暂停播放，重新打开不会自动恢复旧播放。
- Windows 双击或“打开方式”打开的 Markdown/文本可直接编辑并按 Ctrl+S 保存原文件，不自动导入项目。原编码/BOM/统一换行保留，保存前备份，冲突不覆盖。重新明确打开同一路径时可恢复本地未保存草稿。
- Word 默认“文档预览”，显示标题、文字样式、表格与支持的内嵌光栅图片；“编辑文字”保留未改文字的 run 样式和其他 ZIP 资源。精确分页、页眉页脚、浮动排版及旧 .doc 不属于本次编辑范围。
- Word 图片按需读取：最多 32 张，单张 4 MiB、合计 8 MiB、每张 4000 万像素；预览图最长边 1600 像素，动画显示首帧，原图不改变；外链、不支持格式或超限内容显示提示。无图片常驻任务，索引只读纯文本。

## 0.3.9：拖动整理项目分类

- 在项目库左侧将一个自定义分类拖到另一个分类上，即可成为它的子分类。例如将“222”拖到“1111”，成为“1111 / 222”。分类里的项目和下级分类保持原有归属，磁盘目录不移动。
- 拖到“全部项目”可将分类移回项目库顶层。松手前显示目标，Esc 取消；不能拖入自身、自己的子分类或当前父级，同一层重名会提示并保持原状。
- 触屏可用分类握柄；也可以通过“编辑分类 → 上级分类”整理。项目行拖动归类继续保留。“未分类”仍为固定系统分组。
- 无新增依赖、模型或空闲轮询。完整包保留 0.3.8 的缩放配色、项目重命名、媒体暂停、外部 Markdown 编辑与 Word 结构预览修复。

## 0.4.0：Word 编辑稳定性与静态文件预览

- Word 编辑每页最多 40 段，不一次创建成千上万个输入框；跨页保留草稿，支持页码跳转、中文输入保护和返回页码。段落分页是编辑分组，不是 Word 的打印页码。
- SVG 支持轻量静态预览与缩放；使用现有浏览器，不增渲染依赖。原 SVG 不改写；基本图形、文字与渐变经有界白名单重建，脚本、外链、动画、滤镜、虚线描边和其他不支持内容明确提示。列表只显示 SVG 图标，不后台解析所有 SVG 或生成缩略图。
- HTML/HTM 支持只读源码和静态结构预览。文字、标题、列表、表格等按统一样式显示；不运行脚本、不联网、不跳转，图片显示文字占位，不还原原网页 CSS。隔离 iframe 与限制性 CSP；原 HTML 不改写，复杂结构可退回只读源码。
- 新格式各限输入 1 MiB、最多 2000 个内容节点与 32 层嵌套；SVG 另限制路径、引用和尺寸复杂度，超限请用原应用查看。只在打开详情时解析，不新增模型、依赖或空闲轮询。
- 保留 0.3.9 的项目分类拖动和此前所有修复。Markdown 拖入 Word 等文件建立链接尚未包含在本版。

## 0.4.1：SVG 装饰效果兼容修复

- 修复轻量 SVG 因包含投影滤镜或虚线而整张无法预览的问题。保留静态主体，省略滤镜、把虚线显示为实线，并在预览内提示简化效果；原文件不改写。
- 脚本、外链、事件和动画等限制仍保留，解析与复杂度上限不变。没有新增依赖、模型或空闲任务。
- 保留0.4.0的Word编辑分页和HTML静态预览。文档内分层搜索、Markdown拖入Word等文件建立链接仍为后续需求，本版未实现。


## 0.4.2 资源操作与画板

“全部资源”下方新增“未分类”，与下方具体分类分隔。资源空白处右键可粘贴文件、新建文件夹、新建画板和笔记。复制本机文件后按 Ctrl+V 会复制到当前分类或文件夹；在全部资源中粘贴放入未分类。同名文件自动编号，保留来源。编辑正文时 Ctrl+V 保持文本粘贴。

画板使用本地 Excalidraw 编辑器，支持图形、箭头、中文文字和图片。Ctrl+S 保存为 .excalidraw，沿用版本备份与冲突保护；关闭未保存画板会提示。画板不加载外部网页，文件上限 2 MiB。

打开文件夹、在文件夹中显示文件会请求将对应资源管理器窗口前置；用本机应用打开由桌面窗口发起。

## 0.4.4：文档查找、文件链接与容量管理

在文稿中按 **Ctrl+F**，或点文档工具栏的查找按钮，可查当前正文和未保存草稿；Enter / Shift+Enter 前后跳转，Esc 收起。Word 查找可以跨段落分页定位，翻页保留编辑。点回资源区后 Ctrl+F 查当前分类/文件夹，**Ctrl+K** 始终查所有项目。

把项目里的 Word、图片或其他文件拖入可编辑的 Markdown 正文，会在原选区末尾插入链接，保留已选文字。从资源管理器拖入时，先保存副本到当前笔记项目的“参考资料”，再插入链接；原文件保留。ZIP 请先导入再链接其中的文件。链接可在实时预览或阅读预览点击；位于正在编辑的行时显示 Markdown 源码，移开光标后恢复显示。项目文件改名、移动后，映序可通过登记标识继续打开；其他 Markdown 软件使用其中的普通相对路径。

在设置的 **存储和历史版本** 中先查看容量，再确认清理。缩略图可重新生成；旧文稿历史是恢复点，默认不选中。若选择清理历史，可设置保留天数和版本数，至少保留最新一个；清理后无法恢复被清理的旧版本。原稿、项目和数据库不受此清理影响。修改选项后必须重新预览；目录过大或发生变化时会说明无法处理的原因。

右键空白处依次提供新建笔记、文件夹、画板，再到粘贴与打开目录。多选菜单标明数量，删除单独放在末尾。设置顶部显示界面和后台版本，便于核对完整更新是否生效。
