# 映序功能指南

[返回映序](../README.md) · [安装与运行](安装与运行.md) · [开发说明](开发说明.md)

本指南对应 **0.3.2**。从项目建立、素材进入、文件编辑到审核和交接，按日常操作查找入口即可。

## 1. 建立作品的项目空间

左上“项目空间”旁的 **＋** 创建项目，填写名称和简介。项目会生成普通目录和必要的项目入口文件；项目名称可以通过项目旁的“…”菜单修改，修改显示资料不会搬动项目根目录。

| 左侧分类 | 建议放什么 |
| --- | --- |
| 剧本与文档 | 故事大纲、完整剧本、分集梗概、制作笔记 |
| 分镜 | 镜头脚本、镜号与视听参数、分镜参考 |
| 角色 | 角色设定、三视图、服装、表情与参考图 |
| 场景 | 环境设计、空间基准、场景图片 |
| 道具 | 道具设定与图片、关键物件 |
| 白模预演 | 3D 源文件、空间预演、白模渲染视频 |
| 生成素材 | 已生成的图片与视频、候选版本 |
| 成片交付 | 最终成片、交付说明及相关文件 |
| 参考资料 | 风格、历史、视觉或技术参考 |

这些分类用于组织，不限制同一文件与多个镜头建立关联。

## 2. 建文件夹，按集数整理

先进入一个分类，点击顶部 **“新建文件夹”**。打开文件夹后继续新建，即可建立更深层级。示例结构：

```text
角色
├─ 跨集共用
│  ├─ 主角
│  └─ 固定配角
├─ 第 1 集
│  └─ 临时角色
└─ 第 2 集
```

用顶部路径导航返回上层。文件夹可通过“…”或右键菜单进入、重命名、在资源管理器打开或删除。文件夹改名会同步项目内的真实目录；同名冲突不会覆盖已有目录。

共用角色只需保留一个条目，再关联到不同分镜。文件夹负责存放，关联负责表达“这个镜头用到了谁”。

## 3. 文件怎样进入项目

| 方法 | 操作 | 磁盘上发生什么 |
| --- | --- | --- |
| 拖入文件 | 打开目标分类 / 文件夹，从资源管理器拖进工作台 | 复制到项目，外部原件保留 |
| 导入已有文件或目录 | 点“导入”，选择文件 / 文件夹或填入绝对路径 | 建立引用，原文件不复制、不搬动 |
| 新建文档或分镜 | 在对应位置新建并写内容 | 在项目内创建 Markdown 文件 |
| 同步项目文件 | 外部工具改过文件后点击“同步项目文件” | 增量刷新索引，保留标签、状态和关联 |

大型已有素材库适合引用导入，减少重复占用。引用文件仍可在支持的编辑器中保存，**保存会修改那个源文件**，此前版本会备份；引用不等于不可编辑的副本。

## 4. 移动、命名与打开文件夹

### 调整位置

- 将文件卡片拖到左侧分类、当前文件夹卡片或路径导航。
- 也可以在文件的“…” / 右键菜单中选择 **“移动到…”**，再选择分类和目标文件夹。
- 勾选多项后使用顶部 **“移动到”**，一次处理所选文件。

项目内文件会实际移动；外部引用只调整工作台的分类和文件夹，保留源位置。目标有同名文件时会提示冲突，不覆盖原文件。批量移动失败时会回滚本次操作。

### 两种名称

| 入口 | 影响 |
| --- | --- |
| 右侧制作信息中的“显示名称” | 只改卡片和标签页上的名称，不改变磁盘文件名 |
| “文件重命名”或右键“重命名文件” | 同步真实文件名，保留扩展名，更新映序中的文件引用 |

### 在资源管理器中找到内容

0.2.1 支持在文件卡片、列表行、项目或目录入口使用右键菜单。文件选 **“打开所在文件夹”**，文件夹选 **“打开文件夹”**，项目选 **“打开项目文件夹”**；右侧资源信息也保留“定位文件”。菜单还可以通过“…”打开。

支持键盘菜单键或 `Shift+F10` 打开当前元素的菜单，方向键切换选项，`Esc` 关闭。目录入口只定位目录，不运行目录中的文件。

### 把文件交给其他软件

桌面版打开文件后，按住右侧 **“拖出文件”** 手柄，拖到资源管理器或支持接收文件的剪辑软件。它交出实际文件路径并保留原件。不同应用的接收行为取决于该应用；不接收时先“打开所在文件夹”，再从资源管理器操作。普通浏览器使用目录定位入口。

## 5. 在多标签工作区写文档

点击卡片打开标签页，继续点击其他文件可多开。切换标签不会立刻丢弃未保存内容。可拖动分隔线改变区域宽度，通过工具栏收起右侧资源信息，扩大编辑空间。

| 文件类型 | 当前工作方式 |
| --- | --- |
| Markdown / 文本 | 直接输入，支持编辑、预览及分栏，`Ctrl+S` 保存 |
| `.docx` | 读取并编辑普通正文段落，保存前备份；复杂结构按提示只读 |
| 图片 | 大图预览，查看文件信息与可读取的生成元数据 |
| 视频 / 音频 | 在播放器中预览，能否解码取决于本机环境 |
| PDF | 通过内嵌浏览组件查看；环境不支持时用本机应用 |
| 3D / 其他文件 | 管理分类、状态和关联，使用“本机打开”交给对应程序 |

关闭有修改的内容时会提示保存、放弃或继续编辑。文件若被其他工具更新，保存会检查版本，避免直接覆盖外部修改。侧栏“保存前的版本”显示已保留的本地备份；页面草稿不代替文件保存和完整备份。

`.docx` 不是完整排版编辑器：段落内的混合字体或样式在修改后可能简化，表格、复杂版式与旧 `.doc` 推荐在 Word / WPS 中编辑后同步。

## 6. 标签、待审核与分镜信息

### 标签在哪里添加

1. 打开文件，在右侧 **“资源信息 → 制作信息”** 找到“标签”。
2. 输入例如 `信封，关键道具，第1集`，用逗号分隔。
3. 点 **“保存制作信息”**。卡片下方就会显示标签。

标签没有预设含义，可按作品需要命名。右侧不见时，点击工具栏 **“显示资源信息与关联”**。

### 待审核在哪里看

同一面板中的 **“制作状态”** 可以选择：待开始、进行中、待审核、已完成。设置后保存制作信息。

集中查看时，先选择 **“全部资源”**，在列表上方 **“全部状态”** 中选择 **“待审核”**。在某一分类内筛选，只显示那一类的待审核文件。看板也可以按状态查看工作。

### 分镜怎么记录

展开 **“分镜与生成参数”**，填写镜号、时长、景别、摄影机 / 运镜、提示词、反向提示词、种子、版本和模型。制作备注可记录下一步调整意见。

“原文件中的生成信息”来自可识别的 PNG 元数据，可查看与复制；它与自己填写的制作参数分开保存。文件中不存在这些信息时不会凭空生成参数。

## 7. 让分镜与素材互相对应

在右侧 **“关联资源 → 添加关联”** 中选择用途，再搜索当前项目内的文件。可关联角色、场景、道具、白模参考、生成版本、关联文档与参考资料。

例如：镜头 `01-03` 关联“主角设定”“雨夜街口”“信封”“白模预演 v1”和“生成视频 v3”。后续打开镜头就能找到这次创作采用的资料，也能从关联端继续查找。

解除关联只删除关系，不删除文件。目录、标签、状态和关联分别表达存放位置、检索词、制作进度和创作关系，可以组合使用。

## 8. 搜索与筛选

按 `Ctrl+F` 聚焦当前工作台搜索，`Ctrl+K` 仍可使用。可以输入普通中文，也可组合条件：

```text
雨巷 tag:夜景 type:video status:待审核
```

表示同时匹配“雨巷”、夜景标签、视频类型和待审核状态。支持 `tag:`、`type:`、`status:`、`category:`；例如 `category:scenes` 表示场景。高级检索提供类型和状态控件，无需记住所有语法。

搜索在当前项目、分类和文件夹范围内生效。需要找整个项目时先回到“全部资源”；文件夹直属与全部范围也会影响结果。列表按页展示，不会为了翻页把全部素材持续堆进页面。

## 9. 删除与恢复

文件、文件夹、项目和自建 SKILL 都有删除入口。选中多个文件可批量删除；操作前会确认，完成后可立即“撤回”，也可从左侧 **“回收站”** 恢复。

- 删除会从工作台当前列表移出，**磁盘文件保留**。
- 文件夹 / 项目删除按本次操作记录批次，恢复不会把更早已经删除的条目全部重新加回。
- 所属项目也被删除时，先恢复项目，再处理其内部条目。
- 外部 SKILL 使用“隐藏”，源技能文件不卸载；恢复后可重新参与工作台使用。
- 回收站支持名称搜索与分页。

需要进一步清理时，在回收站条目右侧点 **“删除”**，或使用顶部 **“清空回收站”**。映序先列出原文件位置、外部引用说明与冲突原因；确认后，把可处理的项目内文件移入 Windows 回收站。清空操作针对全部回收条目，不受搜索和分页影响。

成功后条目不再出现在映序回收站，也不能从映序点击恢复。误操作时，请到 Windows 回收站还原文件；如需恢复映序的制作状态和关联，仍应保留应用数据备份。外部引用与外部 SKILL 只清理映序记录，原文件保留。已恢复、被其他项目使用、包含未知内容或在预览后发生变化的对象会被拒绝；失败条目保留记录。程序不会降级为永久删除。

## 10. 集中管理 SKILL

左侧 **“SKILL 库”** 可搜索和查看本机用户技能。默认发现 `.codex/skills`、`.claude/skills` 中的用户技能；点“扫描本机 SKILL”刷新。

已有技能只读，需要调整时使用 **“复制为我的 SKILL”**；也可创建新技能，写下自己的视听规范、角色一致性要求或审核方法。在技能右侧点 **“加入当前项目”**，将它写入该项目的交接资料。项目绑定可以随时解除。

绑定表示让后续协作者知道这份规范的位置与用途，不会自动安装、执行或上传技能。

## 11. 把当前进度交给 Codex

进入 **“AI 协作 · 项目交接”**。页面显示最近汇总时间和同步状态；变更未汇总时先“刷新进度”，然后“复制给 AI 的交接指令”。

项目中有这些普通文件：

| 文件 | 内容 |
| --- | --- |
| `AGENTS.md` | 新项目的协作入口，指向项目交接内容 |
| `.yingxu/PROJECT_CONTEXT.md` | 可读的项目说明、当前进度与协作线索 |
| `.yingxu/progress.json` | 结构化制作进度、目录和状态 |
| `.yingxu/files-index.jsonl` | 按行保存的文件索引，便于逐条读取 |

在 Codex 或其他具备本地文件读取能力的工具中打开项目目录，再告诉它：

> 先读 AGENTS.md 和 .yingxu/PROJECT_CONTEXT.md，告诉我目前做到哪一步，再按我的要求继续。

快照会标记生成时间。映序提供本地交接资料，不会替你发送任务；向外部工具分享文件前由你决定分享范围。

## 0.3.0：直接拖拽与连续多选

- 图片、卡片和列表行都能直接按住拖动，无需点小箭头。放到映序内分类或文件夹会移动；拖到桌面、资源管理器或支持文件接收的软件会交付原始文件，保留映序内原件。
- 先点第一项，再按住 Shift 点最后一项，选中当前页面中间整段素材；也支持从后往前选。Ctrl 点选增减单项，Ctrl+Shift 可追加一段。复选框同样支持 Shift 连选。
- 连选按当前可见顺序生效，翻页、筛选或切换分类后重新选择起点。选中多个素材后，拖动其中任意一项即可一起拖拽。


## 0.3.2：右键笔记与快捷入口

- 在项目素材区右键选择“新建笔记”，笔记会放入当前分类或文件夹。
- 在 SKILL 上右键选择“打开文件位置”，Windows 会定位原技能文件；外部技能仍保持只读。
- 顶栏的设置与使用指南图标分别打开对应内容，鼠标悬停可查看说明，也可通过键盘访问。

## 0.3.1：项目库、设置与托盘

点击侧栏“项目库”，用分类文件夹整理长期项目。可创建多层分类、改名、移动分类和给项目归类；只能删除不含当前项目和子分类的空分类。回收中的项目若原分类已删除，恢复后进入未分类。分类只改变项目库归属，不移动磁盘目录。打开项目后侧栏最多显示当前与最近 5 项，全部项目仍可从项目库检索。

点击“设置”可分别控制普通删除、清理回收站时是否弹出确认，默认开启。关闭提示后仍会校验删除范围、共享引用和文件变化；存在无法处理的条目时继续显示原因。只有 Windows 确认回收成功才清除映序记录。

还可设置关闭窗口后留在托盘、启动时视图与排序、音视频自动播放。托盘图标双击重开，右键可打开工作台、设置或退出桌面窗口；退出前处理未保存文稿。后台索引服务独立运行，避免关闭桌面打断导入。

“预览本地文件”提供只读预览；也可在设置中将映序添加到 Windows“打开方式”候选，并可随时撤销。该操作不替换系统默认应用。支持文本、Markdown、Word 正文、PDF、图片、音频和视频；不复制原件、不自动加入项目。视频能否直接播放取决于 WebView2 解码支持。外部预览在后台重启后需重新打开文件。
