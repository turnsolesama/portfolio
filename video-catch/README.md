# 拾影 VideoCatch 0.3.0

Windows 10 / 11 x64 视频发现与原文件下载小程序。独立桌面窗口，可选择 Chrome / Edge 标签页（包括后台标签页）监听媒体请求，选中发现的视频后保存到本地。也可导入其他软件复制的视频直链或网页分享链接。

## 下载与独立扩展

- **[下载 Windows 程序 0.3.0](https://github.com/turnsolesama/portfolio/releases/download/videocatch-v0.3.0/VideoCatch-v0.3.0-Windows-x64.zip)**：完整解压，双击 `VideoCatch.exe`，保留 `_internal` 等全部文件。自带 Python、yt-dlp、FFmpeg、Deno 和 YouTube JavaScript 解析组件，无需另装运行环境。
- **[单独下载 Chrome / Edge 扩展 0.3.0](https://github.com/turnsolesama/portfolio/releases/download/videocatch-v0.3.0/VideoCatch-Extension-v0.3.0.zip)**：独立扩展包，不需要从程序包中寻找。解压后的 `VideoCatch-extension` 是要导入浏览器的文件夹。
- 程序与扩展需要配合使用。扩展不能独立下载；只粘贴网页链接下载时可以不安装扩展。校验信息见 [发布目录](https://github.com/turnsolesama/portfolio/tree/main/video-catch/releases)。

**扩展必须单独放在固定位置；导入后不能移动或删除这个文件夹。** 推荐放在桌面「拾影浏览器扩展」或自己的固定工具目录。浏览器直接读取该目录，ZIP 可以删除，解压后的文件夹必须保留。程序包中也保留 `extension` 副本供备用。

## 第一次使用监听

1. 先打开桌面程序。Chrome 地址栏输入 `chrome://extensions`，Edge 输入 `edge://extensions`；开启「开发人员模式」，点「加载解压缩的扩展」，选择固定目录中**直接包含 manifest.json 的文件夹**，不要选择 ZIP 或它的上一层。
2. 在桌面程序点「复制配对码」，打开浏览器工具栏里的拾影扩展，粘贴后点「连接 / 刷新标签页」。多个浏览器需分别安装和配对。
3. 回桌面程序，**单击左侧视频页面，再点「开始监听」**。仅选中一行不会开始监听；已监听条目显示 ☑。按 Ctrl 可多选，停止时选中条目再点「停止监听」。
4. 回到对应网页，**刷新并开始播放**，等待右侧出现视频。后台标签页也可以，但休眠或未产生新媒体请求的页面无法发现新视频。
5. 单击右侧视频，选择保存目录，再点「保存所选视频」。Ctrl / Shift 可多选，最多两个任务同时下载；保存完成后点「打开文件夹」。

顶部步骤提示会告诉你当前缺少连接、监听还是播放。标签页没同步时，点扩展中的「连接 / 刷新标签页」；桌面程序每次重启后配对码会更换，需要重新配对。浏览器超过 95 秒未连接会从列表移除，恢复后重新开始监听。

### 已经安装过旧版

关闭旧桌面程序，使用新版 EXE。把新扩展文件复制到原来的固定扩展目录，覆盖同名文件，在扩展管理页点「重新加载」，检查版本为 0.3.0，再配对并刷新视频网页。若要改成新的固定目录，请先移除旧扩展再从新目录加载。不要同时加载两份拾影扩展。**桌面程序和扩展要一起更新**，旧版桥接协议无法连接新版扩展。

### B 站

开始监听 B 站标签页后会出现「B站页面解析」。刷新并播放，**等条目变成「B站音画合并」再保存**，会下载播放器可访问的视频和声音轨道并无转码合并。仅显示页面解析时也可尝试保存，但可能受站点验证影响。切换视频或分 P 后信息未更新时，请刷新网页。

### YouTube

可直接粘贴视频链接，或对视频标签页开始监听。带播放列表、电台参数的链接会归一为单个视频，避免下载整张列表；零散 googlevideo 音视频请求合并为网页解析入口。新版自带 Deno 与 yt-dlp-ejs，用于 YouTube 的 JavaScript 解析。

**浏览器能播放，但下载超时：** 点击下载区域「检测本机代理」。检测成功会为本次下载选用可连接 YouTube 的本机代理；也可手动填写自己的 `http://127.0.0.1:端口` 或 `socks5://127.0.0.1:端口`，再选中失败条目重新保存。需要本机已有可用代理服务；程序不提供节点。网络选项只作用于新加入的下载任务，不更改系统或浏览器代理，退出后不保存。检测仅检查常用本机端口并访问 YouTube 连通性页面。

### 其他网站或软件

未发现直链时，可点「直接添加所选页面」；也可将其他软件复制的 HTTP/HTTPS 视频直链或网页分享链接粘贴到「其他来源」。不支持任意桌面进程的 HTTPS 嗅探，无法复制链接的专有客户端不在本版范围内。网页解析的兼容范围取决于站点，不保证所有视频都可下载。

## 保存方式与范围

| 来源 | 处理方式 |
| --- | --- |
| MP4、WebM 等普通文件 | 下载原始媒体；本地测试逐字节 SHA-256 相同 |
| B 站 DASH 音视频 | 从已播放页面获取成对轨道，下载并无转码合并；清晰度取决于页面当前可访问的格式 |
| HLS `.m3u8`、DASH `.mpd` | 获取分段并合并，无主动转码；不是逐字节相同的单个服务器文件 |
| 支持的网站页面 | yt-dlp 解析，自动选择可用的最佳画质并在需要时合并音轨 |
| 直播 | 下载期间持续获取可用分段；取消可能只留下未完成文件，本版不保证直播停止后自动封装 |
| DRM / 专有加密 / 付费访问控制 | 不提供绕过；不能保证下载 |

网页可能有广告、不同清晰度、独立音视频轨道，发现的条目不保证都是主视频。对于单独的无声音轨视频地址，优先导入页面链接或选择包含完整音轨的主清单。`.ts` / `.m4s` 不作为独立完整视频列出；B 站通过页面信息合并轨道，其他站点通过网页解析兜底。`blob:` 是浏览器内存引用，不能作为原视频 URL 导入；可对包含播放器的网页进行解析，或使用底层可见的 HLS/DASH 清单。

后台标签页需要仍在请求媒体；被浏览器休眠的页面不产生新请求。已缓存视频需刷新，浏览器内部页、无痕页、某些 Worker 或专有播放协议不能保证发现。Firefox / Safari 未适配。

本版不读取 Cookie、Authorization 或浏览器密码。需要登录凭证、短期签名、防盗链、验证码或特定 JavaScript 执行环境的网站可能失败；出现 403 等错误时重新播放、捕获新链接，或用网页分享链接重试。本地已验证并不代表所有第三方站点均可用。

## 数据和控制

- 本机桥接仅监听 `127.0.0.1:18796`，通过随机配对码验证请求，不修改系统代理、不安装证书、不要求管理员权限。
- 扩展有 HTTP / HTTPS 站点访问权限，以发现跨域 CDN 媒体；只读普通请求上下文，不修改请求。标签页元数据发到本机供选择，未勾选的媒体不进入桌面候选列表。
- B 站页面内观察初始播放数据赋值及播放器自己的 fetch/XHR playurl 响应，保留媒体字段的内存副本；不改变返回内容，不主动调用播放接口，不读取 Cookie。只有勾选后才将媒体地址交给桌面程序。离开页面或关闭程序后清空，临时签名 URL 不写入发布包。
- 配对码保存在扩展本地存储；桌面中的发现记录、URL 与请求上下文仅驻留内存，退出清空。不会主动上传视频或记录到第三方服务。下载会访问对应媒体网站。
- 默认目录为用户的 `Videos/VideoCatch`；实际开始下载或打开目录时创建。保存目录不持久化，重启恢复默认。
- 取消会停止该任务及 FFmpeg 子进程；已产生的 `.part` 等临时文件保留。程序打开期间可重试，关闭后需要重新发现或导入链接。
- 清除列表记录不删除磁盘视频，已经保存的文件不会被覆盖。

## 开发和验证

在本目录运行：

```powershell
python -m venv .build/venv
.build/venv/Scripts/python.exe -m pip install -r requirements.txt
.build/venv/Scripts/python.exe app.py
.build/venv/Scripts/python.exe -m unittest discover -s tests -v
node --test tests/extension.test.cjs
.build/venv/Scripts/python.exe prepare_runtime.py
.build/venv/Scripts/python.exe build.py
```

构建产物位于 `releases/`。构建只选择程序依赖和明确列出的文档、扩展文件，不包含下载内容、个人配置或测试环境。依赖版本及 SHA-256 记录在包内 `runtime-manifest.json`，许可见 `licenses/`。

实现参考：[Chrome webRequest 官方文档](https://developer.chrome.com/docs/extensions/reference/api/webRequest)、[yt-dlp 官方文档](https://github.com/yt-dlp/yt-dlp)、[imageio-ffmpeg](https://github.com/imageio/imageio-ffmpeg)。
