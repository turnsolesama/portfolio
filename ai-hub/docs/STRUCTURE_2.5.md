# AI Hub 2.5：分类与项目管理

这是对现有扫描、SQLite、模型标签及桌面入口的增量升级。保留原界面风格与数字分区，不迁移真实资产。应用、前端及发行包版本为 2.5.0；桌面壳保留 2.4.1，图标及桌面行为未改动。

## 项目与知识

侧栏新增“项目与运行”。创作项目发现范围为 `40_Projects`；训练项目为 `50_Training/Projects`；工具开发通过明确项目说明或人工登记接入。发现的目录显示“未登记”，不推断进度或验证结论。

每个登记包含项目类型、当前说明、资产位置、输出位置和一个明确的正式交付位置。通用、影视、训练模板各有适用类型与版本；已有应用选择“仅映射”，保留自己的内部目录。编辑后先查看预览，再保存位置登记，软件不创建项目资产目录。

新运行按项目和运行编号登记。推荐 `70_Output/Projects/<项目编号>/<运行编号>`；无项目测试采用 `70_Output/Tests/Unassigned/<运行编号>`。已存在的应用输出可显式映射，不根据历史散图名称自动认领。正式交付位置由项目登记唯一确定，Media 不复制已有项目交付。

“知识与报告”加入项目说明、`80_Knowledge/Guides` 顶层正文与显式登记的其他知识正文，可搜索和按组筛选。深层资料用知识登记或 `80_Knowledge/manifest.json` 白名单接入；不递归读取构建材料、配置、依赖和缓存。格式见 [登记规则](REGISTRY.md)。

## 分类与入库

四个维度分别显示：所属范围、模型角色、创作用途、兼容架构。LoRA 仍支持风格、人物、光照等多个用途。未知类型不会归为 Private；“应用私有”只用于所属范围。

人工分类优先。模型浏览、详情、预览和整理共用分类上下文；列表先分类筛选、再按文件身份去重分页。对同一文件的多个有效入口，编辑保留其他维度的最新人工值，恢复自动分类清除该身份的人工覆盖。旧路径若已被独立文件替换，不再视作原文件别名。

“已索引”表示扫描找到；“已登记”表示匹配当前稳定台账；“分类待确认”说明至少一个分类维度仍缺证据。这些状态可并存，人工写一个用途不会自动成为稳定登记。目录快照时间与现场索引时间分别展示，文件记录数不等于模型包数或独立版本数。

## 验证状态

工作流区分待验证、仅路径检查、历史执行通过和当前复验通过。登记执行通过必须绑定日期、工作流 SHA-256、依赖快照及输出证据；当前复验状态还需与现有文件匹配。文件变化会降级显示；运行状态同步重新计算。

可以粘贴依赖与输出位置，使用“读取文件信息”生成快照。此操作只计算工作流哈希、读取依赖与输出的大小及修改时间，不执行模型、不预览图像，也不自动填写通过结论。元数据快照不能发现恶意保持大小及时间的内容替换；有更强核验需求时可按登记格式提供摘要。

## 模型库和整理

- Library 是既有分类入口。
- Runtime 保持应用模型引用路径。
- Packages 保存配置与分片的完整配套关系。

检测到既有模型库时，整理只提供统一视图；执行和启动整理均被阻止，不生成第二棵 `00_AIHub_Library`。模型分片可出现在索引中，不拆包。全新散落资产安全区保留原预览、明确确认、建立硬链接与撤销流程。硬链接与原件共享内容，不是备份。

## 数据迁移与回退

只为 `model_labels` 增加 `scope`、`model_role`、`architecture` 三个可空字段。旧表升级前使用 SQLite backup API 保存含 WAL 的一致快照，校验成功后才执行事务迁移；失败回滚。模型、评分、备注、来源、旧标签值和桌面配置不被重写。

项目与证据保存在本机 `data/registry.json`，预览 token 绑定当前登记版本；保存前再次校验，原子写入并保留上一个有效版本。界面“登记回退”先预览再恢复。损坏文件不会被静默覆盖。

数据库回退工具只生成一个独立文件，不覆盖运行中的数据库：

```powershell
python tools/restore_database.py --backup "备份.sqlite" --output "恢复候选.sqlite"
```

切换旧程序和数据库前停止服务，保留当前数据库及桌面配置，再使用匹配的程序版本和备份；恢复历史快照会回到备份时点，不能保留其后的新登记。此次不合并、不删除、不自动移动模型或图库。

## 开发验证

运行项目现有 Python 与 JavaScript 测试，并追加迁移/WAL/故障回滚、别名标签、身份变更、项目与知识入口、预览并发、证据过期及运行状态测试。合成夹具验证整理执行与撤销，不在真实资产上测试。浏览器连接不可用时，记录为未完成页面目验；自动页面逻辑测试不等于视觉验收。
