# 安全区与自动整理

AI Hub 2.3 不绑定作者的盘符或目录。程序可解压在任意可写目录；资产安全区由这台电脑的使用者设置，例如 F:\AI、D:\CreativeAssets。首次进入“安全区整理”，填写绝对路径；目录尚不存在时勾选创建目录。软件只在点击保存后创建和登记目录，不接管整块磁盘。

## 一次完整的整理

预览先识别目录策略。如果安全区本身或其直接子目录已有 `20_Models`、`Library`、`Runtime`、`Packages`，使用 `existing_library_view`：统一虚拟分类视图，目标为 null，`apply_allowed=false`。不会另建 `00_AIHub_Library`；执行接口和后台启动整理都拒绝该策略。已保存的旧开启设置也不能绕过这一检查。空白的标准目录同样先受此保护，后续实体目标策略需单独审查，不能仅靠打开开关解锁。

以下建立硬链接步骤只适用于没有上述模型库标记的便携资产安全区（`portable_hardlinks`）。

1. 保存安全区。新建时准备管理、应用、模型、素材、项目、训练、工作流、输出、知识和归档目录；既有目录内容保持原样。
2. 点击预览，后台递归识别安全区中的普通资产。查看原路径、分类入口、分类依据、略过数量及限制提示。
3. 点击建立分类入口。在安全区的 `00_AIHub_Library` 内按模型用途、LoRA 用途以及图片、视频、音频、工作流、文档类别建立硬链接。
4. 查看执行记录；需要时撤销某一批入口。原位置和文件名保持不变，现有软件与工作流继续使用原路径。

硬链接是同一个文件的另一入口，共用文件内容：编辑任一入口会同步改变原文件。它不是独立备份，也不代表释放了磁盘空间。AI Hub 整理只读取资产、建立入口，不修改文件正文。需要备份时请使用独立的备份方案。

## 自动运行

可在便携硬链接策略下保存“启动时自动整理”。此设置默认关闭，只对已保存且仍符合该策略的安全区生效；每次后台服务启动时建立新入口并刷新索引。已有模型库仅能预览，禁止启用和执行启动整理。关闭桌面窗口会保留服务，因此仅重新打开窗口不一定触发新一轮整理。不安装系统开机任务，不实时监听文件夹。

安全区失效、换盘符或移动到其他电脑时，首页提示重新设置，自动整理暂停。重新保存路径后再预览。发行包不含你的 `data/`，新用户从空配置开始；升级同一台电脑则保留原 `data/`。

## 分类依据与边界

- 模型优先读取 safetensors 元数据，仅解析文件头，不加载模型、不反序列化 pickle。功能与架构兼容信息分开；证据不足保留待确认。
- LoRA 风格、光照、角色等用途是现有元数据或文件名支持的建议，不代表已验证生成效果。多用途或未知分类以预览说明为准。
- 图片、视频、音频按格式分类；JSON 只在确认符合工作流结构时加入。不会把任意 JSON 配置当工作流。
- 应用、依赖环境、项目与训练包、隐私配置、原有分类库和目录联接不做拆散整理。已有模型库的普通模型路径可纳入虚拟预览；不进入模型包读取配置，包内已索引权重仅用索引和文件身份进入视图。不移动模型分片，不合并或去重删除原件。
- 模型浏览与预览共用稳定台账、模型索引、人工覆盖和文件身份上下文，显示相同的所属范围、角色、用途、架构与登记状态。执行前重新读取人工覆盖；分类已经变化则跳过旧计划，不按过时分类建立入口。
- 同一设备号/inode 只列一项，其余路径作为兼容入口显示；逻辑体积只计一次，不据此宣称释放磁盘空间。无法验证的身份不合并。
- 不沿符号链接、目录联接或重解析点进入其他位置；安全区不能是盘根、系统目录或用户主目录。也不允许以联接路径变相扩大范围。
- 目标已存在时不覆盖。文件从预览后发生改变时略过；权限不足、硬链接不可用等失败会记入结果，不改为复制或删除。
- 每轮最多列出 50000 个新增候选；执行后再预览会跳过已有入口并继续后续候选。单次最多遍历 500000 个目录项；达到总遍历上限时会提示缩小安全区分区检查，未完整检查的目录整体略过。不能把达到上限的结果视为全区完成。

整理与扫描互斥；建立入口前再次核对路径边界和文件身份。执行日志保存在本机 `data/organizer`。撤销只移除该批次仍与原件匹配且未发生变化的入口，遇到变化保留并报告。已创建的空分类目录可能保留。不要手工改写日志或把硬链接当作独立副本。
