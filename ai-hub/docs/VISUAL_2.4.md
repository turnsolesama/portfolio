# 2.4 视觉更新与验证

本版调整 AI Hub 的视觉层级与日常入口，并与 Codex Switcher 2.4 的炭灰 / 冰蓝配色协调。

## 设计参考

- [Linear 界面重设计](https://linear.app/now/how-we-redesigned-the-linear-ui)：参考导航、内容区、表头与面板的层级，以及更清晰的对齐与信息密度。
- [Raycast 主题](https://manual.raycast.com/themes)：参考深色背景与控件的关系。没有复制品牌素材，也没有加载外部字体或资源。

## 变化

- 紧凑导航和顶栏，移除主区域外侧重复边框，扩大可用内容空间。
- 首页提供模型、图库、工作流三个常用入口；按创作用途的分类提前到维护信息之前。
- 四项核心统计整合为一条分隔清楚的统计区；窄窗口改为两列。
- 列表、筛选、详情、图库、整理页面共用中性色阶、柔和强调色、细边框和一致的按钮状态。
- 按钮悬停仍保持深色；主按钮采用深色文字。图库删除按钮在平常、悬停与键盘焦点状态均可辨识。
- 保留现有导航、返回恢复、筛选、图库回收站删除和安全区整理行为。

## 维护

样式入口为 `frontend/atelier.css`，加载在基础样式与 `studio.css` 之后。新组件优先复用现有 CSS 变量，不增加在线依赖。窗口宽度覆盖 620 / 800 / 960 / 1180 像素分段，沿用减少动画偏好。

这是前端更新，沿用经过验证的桌面 EXE 和 2.3 后台协议；不修改模型、索引或用户配置。已打开的页面需重新加载才能显示新界面。
