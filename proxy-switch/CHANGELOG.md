# 版本记录

## 3.1.1

- 修复打包应用启动的管理器与普通桌面入口因 MSIX AppData 重定向读取不同配置的问题。默认本机数据改为 `%USERPROFILE%\.proxyswitch`，管理器、启动入口、安装脚本和后台工作进程统一读取。
- 首次迁移复制当前环境可见的旧数据与快捷方式备份，保留原文件；完整复制后启用，失败不留下半成品。已有新版数据不被旧配置覆盖，不应用历史线路。旧快捷方式的默认 AppData 参数通过迁移记录兼容，其他自定义目录与隔离测试保持原样。
- 启动失败记录实际配置目录与错误，仅保存本机；移除临时 L2 诊断弹窗文字。
- 增加 13 项存储回归断言，总计 188 项。桌面启动与打包进程启动分别验证，避免用一种启动环境代替另一种。

## 3.1.0

- 新增 Chromium/Electron 程序启动代理适配：为界面和支持代理变量的联网子进程同时传入选定 HTTP 代理或直连配置，无需另一个代理客户端充当分流引擎。
- 备份并接入原桌面启动图标；每次启动读取当前程序目标和代理端口。有自定义启动参数的原入口保持原样，另建代理入口。已运行时明确提示完整退出，不把重复启动或保存目标当成生效。
- 程序列表汇总同目录内的联网子进程，显示其入口外连接与 SynSent。没有专用规则时显示“未单独指定”；已保存、需重开、等待连接验证和已观察到目标连接分别显示。
- 统一切换与撤回同时处理程序启动代理和原有引擎规则，保留快捷方式备份与外部更改保护。
- 175 项断言通过，新增真实父子程序的环境继承验证。对目标服务的无凭据连通性检查不能替代用户登录成功验收。

## 3.0.3

- 恢复自动发现后台代理，增加独立开关；识别代理与观察程序连接均保留，网络切换仍由用户触发。
- 自动握手先确认代理内核身份，复核监听归属；成功结果缓存 10 分钟，进程重启或端口变化后重新识别。未知客户端可从当前系统代理和用户代理变量被动加入列表。
- 进程路径改用有限查询权限接口，避免 PowerShell 5.1 的 MainModule 路径查询隐式请求目标进程内存读取权限。路径不可读时保留 PID/名称观察。
- 统一切换的三个网站检查改为并行，任一通过即继续，单项最多 5 秒；新增阶段进度，用户切换优先于后台发现，未变化的用户变量不重复写入。
- 保留系统入口实读、并发选择保护、失败回滚和失效端口检查。已有连接不会被强制断开；按程序分流仍需要受支持的引擎。
- 152 项断言和四种隔离界面回归通过。移除自动发现未能解决此前现场登录失败，随后也出现过保持运行时一次登录成功；游戏错误 [4] 的具体原因尚未确认。

## 3.0.2

- 启动、自动刷新和退出改为被动读取，不主动探测端口，不重新应用历史代理。
- 手动发现仅探测已配置入口和已识别的代理客户端，排除游戏及无关应用的通信端口。
- 普通 HTTP 统一切换直接使用所选端口，避免隐式依赖另一个代理引擎。
- 撤回前检查本地环境变量代理端口，拒绝恢复失效端口；回滚保留其他客户端的最新选择。
- 实际入口与待提交目标分开显示；不凭历史记录认定引擎出口。远程入口不在刷新时主动连接。
- 只读显示路径不可读的游戏进程与 SynSent 代理连接，避免将连接中误报为已连通。
- 增加 19 项兼容性断言和连续刷新、退出的界面验证。游戏错误 [4] 的具体原因仍需现场登录复测。

## 3.0.1

- 启动与定时自动发现后台代理，HTTP CONNECT / SOCKS5 握手通过后补充本机列表。
- 不再把所有候选端口默认当成 HTTP；排除普通网页、控制接口与需要认证的入口。
- 支持未知用户程序、进程路径不可读及 TCP 查询失败时的 netstat 回退。
- 刷新时同步配置文件、代理下拉框与列表，工作线程显式使用当前配置目录。
- 保留代理名称、稳定规则标识与分流引擎；去重保存、变更前备份，已删除入口不会自动加回。
- 系统默认入口与后台代理运行状态分别显示；自动发现不修改网络设置。
- 117 项断言通过，并验证隔离界面的自动发现、配置刷新、删除与重扫。

## 3.0.0

- 固定品牌按钮改为通用代理列表，支持添加、修改、删除 HTTP / SOCKS5 入口。
- 新安装无预设 VPN；旧配置保留名称、路径与稳定规则标识。
- 新增目标下拉框与「统一切换」，同步系统代理和用户变量，撤销程序专用规则并保存可撤回快照。
- 可选分流引擎对统一目标增加默认路由，防止旧程序例外继续分流。
- 实际线路检测失败时恢复规则；原生设置尚未写入前发生外部改动，不覆盖外部更改。
- 移除特定应用启动功能，代理管理与诊断按用户配置动态显示。
- 增加候选端口发现、动态右键菜单、版本迁移与匿名报告。
- 95 项单元断言及 8 种隔离路由实测通过。

## 2.2.0

- 重做状态卡片、程序分流与诊断工具页面，窗口支持缩放。
- 新增程序搜索、已设规则筛选、详情、复制路径、EXE / 快捷方式添加与拖放。
- 新增客户端路径与端口设置、匿名诊断报告和活动日志。
- 本机数据与程序文件分离，便于更新和公开发布。
- 修复 Windows PowerShell 5.1 原子替换文件时空备份参数的兼容问题。
- 端口变化时，已有 Upnet 规则在重载前显示为尚未加载。
- 增加便携源码包、桌面快捷方式脚本、开发检查和显式清单打包。

- 显示实际连接，右键菜单固定目标程序，避免刷新时选错。
