# Codex Switcher 2.4 视觉约定

设计参考：
- Linear 官方界面重设计说明：https://linear.app/now/how-we-redesigned-the-linear-ui
- Raycast 官方主题说明：https://manual.raycast.com/themes

借鉴紧凑导航、层级分明的中性表面、统一主题变量和有限重点色；图形标识为本项目代码绘制，无第三方素材依赖。

与 AI Hub 共用基础色：背景 #111315；面板 #191c20；控件 #23272d；正文 #eef1f5；辅助 #a2aab5；重点 #a9c4ec。状态徽标采用低饱和绿或琥珀色并搭配文字，不只依赖颜色区分状态。

主窗口保留可调分栏，左侧为服务库，右侧为分组详情。顶栏保持紧凑；当前配置与选中的服务分开显示。详情以连接、模型、认证三个组呈现，每行固定标签宽度、剩余宽度自动换行。长名称和地址由详情区滚动；主操作与编辑/副本/移除按钮在滚动区外。主强调色优先分配给应用操作。

维护时在 switcher_ui.py 统一调整配色和间距；每个 hover/pressed/disabled 状态均需明确文字和背景。禁用状态优先于悬停，避免恢复 Clam 默认白色菜单悬停。各状态文字/箭头及状态徽标对比度测试目标为 4.5:1。

验证使用 --demo 和离屏窗口临时配置。四档模拟 DPI：100%、125%、150%、200%。不以控件几何测试冒充截图验收；本轮浏览器/原生窗口查看工具不可用，因此未完成实际截图外观检查。不要读取或复制真实 Codex 配置进行 UI 测试。

发布与安装：使用 package_release.py 白名单；安装前比对源文件基线，只备份和替换程序文件，不触碰 profiles.json、密钥、Codex 配置和已有窗口。程序本身升级不会立即改变已打开窗口，需用户关闭后重开。
