# 开发与验收记录

## 2026-09-11 · 0.2.0 功能与本地验收完成

本轮目标：自动识别本地推理环境和缺失项；将图片、视频 API 工作流封装成可填写参数的工作流包；保持客户端轻量、界面响应及时，并验证实际生成链路。

分工：环境发现、工作流诊断、前端画布与包表单由三个并行子代理负责；主代理负责包存储、输入校验、服务整合、生成链路验收与发布。

### 范围与实现决策

- 自动探测设置地址、少量常用端口以及本机 ComfyUI 进程提供的候选地址，不扫描整盘或局域网。
- 区分确认缺失、检测异常、待核实、暂不可检查和已通过，后端离线不等于所有模型与节点都缺失。
- 工作流包采用有版本标记的 JSON，保存 API 图和参数映射；不包含模型、可执行脚本或媒体文件。模型与节点仍由已有 ComfyUI 提供。
- 开放参数可包含提示词、整数、数值、开关、下拉选项和参考图上传；运行前使用实时节点定义校验。
- 普通 ComfyUI 画布 JSON 需要先导出 API 格式；本轮不猜测 UI 小部件与节点输入的映射。
- 包与用户参数保存在本机数据目录，不进入公开源码、发行包或测试记录。
- 现有模型、参考软件、历史版本和下载地址保留。自动检测只读；不自动下载安装、执行第三方安装脚本或重建已有环境。

### 已发现问题

- 0.1.0 后端离线时仍将未读取到的节点和模型标为缺失；本轮改为未知，避免重复安装。
- 原诊断入口只传模式和模型，不能完整识别参考图、LoRA 与 API 工作流依赖；本轮传完整生成请求。
- 包参数不得覆盖连线、绑定不存在的节点、包含重复映射或非有限数字；JSON 包仅为数据，导入不会运行生成。
- 并行审核修复：深层损坏 JSON 导致请求断开、超大数值边界溢出、种子超出浏览器整数精度、上传途中切后端导致错误归属、扫描期间设置变化导致旧缓存重新生效。
- 并行审核修复：推荐字段名称不一致、参考图字段可取消导致包无法输入图片、前端重新拼接本地检查明细导致脱敏文本回流。
- 共享模型根目录会让嵌入、ControlNet、视觉编码器出现在主模型候选中；已排除这些明确不适用的目录角色，未知自定义模型仍需实际加载验证。
- 验收脚本曾误用 `images` 而非协议要求的 `references`，编译层正确阻止无参考图请求；修正脚本后首帧图生视频完成。界面测试曾用相对地址匹配浏览器解析后的绝对地址，造成假超时；截图和 DOM 确认图片已正确显示，修正断言后通过。这两项不是产品生成失败。

### 结果与性能证据

- 自动环境扫描约 1.4 秒，识别测试后端、关联 Python 与 6 项依赖元数据。未启动的自定义安装仍可能需要用户填写安装目录。
- RTX 5070 Ti 16 GB：Krea 512×512、8 步约 16.3 秒；H3 文生视频约 116.9 秒；H3 首帧图生视频约 120.9 秒，两段视频均 768×448、124 帧、24 fps、5.167 秒。
- Windows EXE 的首次表单图片生成约 12.1 秒。重复相同图命中后端缓存，只用于界面回传验证，不作为推理速度数据。
- 两段视频完整 FFmpeg 解码通过，抽帧能识别茶壶、桌面、光线；图生视频保留参考主体并出现蒸汽。浏览器播放时间推进正常，音轨只检查结构，未评分音质或音画同步。
- 100 节点、66 连线的离屏浏览器检查：源码导入至首次缩放约 130 ms，EXE 约 93 ms；21 次缩放与 16 步拖动序列分别约 562 / 575 ms。包含测试工具开销，不代表桌面 FPS 或其他设备性能。

### 保留的边界

本轮不实现自动安装、完整独立推理引擎、UI 格式工作流通用转换、视频编辑时间线或长片质量保障。H3 双参考首尾帧、Ref2VA、多角色/Turbo 质量、Krea 多图编辑、SDXL 不同模型和其他显卡仍需专项真实验证。检查通过只说明对应范围，不能替代生成与质量验收。
