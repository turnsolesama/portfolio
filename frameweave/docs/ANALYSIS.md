# 参考工具功能分析与初版边界

本次分析基于实际运行的桌面界面、只读本地 HTTP 节点描述和官方模型/ComfyUI 文档。只观察和总结接口行为，客户端为独立实现，没有复制原工具的前端源码、品牌、图标、广告、私人数据或推理插件。

## 观察到的基础结构

参考工具是 Electron 桌面工作台，包含 H3 视频、本地图片、云端图片、对话和无限画布。画布可建立多个项目，使用图片/视频节点和连线，通过节点参数区生成结果；另有导入导出、模型选择、LoRA、任务、历史、小地图、适配视图和提示词素材引用。其底层本地生成服务使用 ComfyUI HTTP API。

观察到的扩展功能还有剪辑、取首尾帧、音频分离、超分、素材库和助手。画布上有推广额度/作者主页入口。这些推广入口与专业画布生成链无关，帧织未加入。

## 发现与设计改进

1. 模型类别如果都映射到同一递归目录，主模型、编码器、VAE、LoRA 可能混进同一个选项列表。帧织先按用途和路径角色过滤，再按模式匹配；选择错误角色会阻止提交。
2. 模型同名和多个兼容目录不等于多份磁盘占用。帧织保留后端原始相对名称，不擅自搬动、删除或合并权重。
3. “服务在线”和“模型文件存在”都不能证明模型能加载、生成正确或足够快。诊断、协议验证和 GPU 实测必须分别报告。
4. 在共享生成后端使用全局 interrupt 有机会终止其他客户端任务。优先原子按任务取消；旧后端限制为排队任务删除。
5. 客户端不用 Electron 捆绑完整浏览器；Windows 便携程序采用系统 Edge 应用窗口和小型本地服务，依赖模型位于外部。

## 不改变现有工作流

帧织以新目录、新端口、新数据目录运行。原软件、运行环境、模型、私有配置、项目历史及旧路径均保留。新生成结果写在后端输出目录的 `FrameWeave/` 前缀下。退出帧织即可停止使用，无需迁移或回滚原软件。

高级 API 图可能包含用户自选的后端插件。导入时检查节点、枚举、连线类型与环；该校验不能证明第三方节点代码安全或替代官方模型许可。
